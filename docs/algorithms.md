# Implemented algorithms and conventions

This file specifies the current Rust behavior. Differences from GUIDE require further work; they are not claims that the original uses these exact choices.

## Data

CSV permits escaped quotes, embedded delimiters/newlines and CRLF. Headers must be unique. Numeric nonfinite values and negative weights are rejected. Missing responses and zero weights exclude rows from fitting. An unspecified schema infers a categorical column if any observed token is not numeric. For fitting linear nodes, users explicitly assign fitting roles to prevent unintended predictors.

Positive classification weights are treated as 1. Priors rescale class contributions by prior divided by training class frequency. Classification labels are sorted strings; fitting requires at least two observed classes (bootstrap samples may omit a class from the global universe). Costs affect predicted classes and pruning risk. Splitting uses prior-adjusted Gini with additional class cost-sum adjustment, weighting child impurities by observation counts rather than prior-adjusted mass. Native fixtures verify the binary prior/cost cases; general multiclass cost behavior remains unverified.

Class counts are accumulated before prior adjustment and normalization; posterior calculation uses prior_j × node_count_j / training_count_j to preserve exact full-sample prior ties. After growth and pruning, if any node posterior is zero, replace every posterior p_j with (N p_j + prior_j)/(N+1), where N is the full training sample size, following manual 46.1 p.27. Otherwise probabilities are unchanged. The correction does not affect split objectives or pure-node stopping. A single tree retains its predicted class chosen from unsmoothed posteriors and costs; ensembles choose from averaged corrected probabilities. Native ensemble probability conventions remain unverified.

## Selection and search

Selection tests are computed from row counts, separately from the weighted objective used in split optimization. Classification uses class labels; regression uses positive versus nonpositive fitted residuals. Classification numerical tests use the mean/standard-deviation groups in Loh (2009), Procedures 2.1–2.2. Regression and importance use quantile groups; small-support numerical importance variables are grouped as categories. Missing values form a separate group.

Pearson statistics discard empty margins. Current selection compares log chi-square survival probabilities using an incomplete gamma calculation, preserving distinctions when ordinary p-values underflow. Bonferroni thresholds are also calculated directly in log space. This differs from the Wilson–Hilferty approximation in the 2009 paper. A main effect is accepted at alpha/K; if none qualifies, pairwise joint-table tests use 2 alpha/[K(K−1)]. Otherwise the best main effect is used. Default alpha is 0.10. Feature-index order breaks association-test ties. For equal numerical classification split losses within the selected variable, the more balanced child counts win; remaining cutpoint ties retain the first candidate.

After selection, candidate splits optimize the sum of child impurities. Numerical cuts use adjacent-value midpoints, restricted to at most 100 evenly indexed candidates by default. Set `max_split_candidates` to 0 for exhaustive cutpoint search. Binary-class and regression categorical search orders levels by the weighted response/class mean, except Poisson uses exposure-adjusted rates; multiclass search enumerates subsets through 11 levels. Multiple-linear squared-error categorical search also enumerates subsets through 11 observed nonmissing levels because response-mean ordering can miss the best slope partition; larger linear designs retain the ordered heuristic. In the bounded linear SSE path, the first local lexical level stays left, with missingness sorted as `NA`; missing-only partitions use the same categorical metadata. Excluded levels cannot anchor a split, and unknown levels go right. Higher-cardinality multiclass search is rejected. Circular predictors enumerate intervals between cyclic midpoints. These searches are not yet all the model-specific searches in GUIDE.

Optional `linear_splits` tests bivariate numerical projections when neither a main effect nor an interaction was selected. Following Loh (2009), observations are trimmed within class at two standard deviations before estimating the leading discriminant direction. The 2×2 between/within scatter problem uses Cholesky whitening with a small diagonal ridge for numerical stability. Complete-case projections receive association tests; incomplete pairs form a missing group and have a learned prediction direction. Regression uses residual classes. Linear-split priority and exact GUIDE numerical regularization remain unverified.

When a pair is selected during fitting, a two-level search evaluates either variable at the parent and the other in each child. This permits a zero-gain first split for pure interactions. Equal two-level losses choose the second variable in the selected pair, matching the native pure-interaction fixtures; equal cutpoint losses retain the first candidate. Importance uses the published immediate split comparison and allows zero-gain intermediate splits. A winning interaction updates importance probabilities for both selected variables and exact typed predictor copies within the node, matching the 42.5 changelog requirement. The default fitting depth is 10, minimum child size 2, and normalized minimum gain 1e-12; these are explicit Rust defaults, not a claim to reproduce every GUIDE adaptive default.

Objective comparisons and pruning ties use a relative roundoff tolerance of 64 machine epsilons, without an absolute floor. Both the early stopping check and the accepted split gain use root-weight-normalized impurity. Thus changing observation-weight units does not alter `min_gain`; changing response units still requires rescaling this explicit loss-unit threshold (invariance tests set it to zero).

Numerical threshold candidates use observed split-value ranks before assigning missing rows: left count must be at least `min_samples_leaf`, right count strictly greater. This asymmetric upper endpoint is observed in both pinned native versions. Repeated observations count separately; routed missing rows do not satisfy these rank constraints. Total child counts must still meet the configured minimum. Missingness-only splits are candidates. With observed missing cases, both missing directions are evaluated. Without observed missing cases, numerical and categorical splits send future missing observations right. Unseen categorical levels go right, as stated in native reports. Binary classification orders category groups by decreasing class-index mean; regression uses increasing response means/rates. Linear and periodic splits retain the larger-child default (left on ties), pending differential checks. Split choices and directions are persisted in the model; loading older models preserves their saved routes and probabilities. Associated missing flags, missing-type aggregation, and forest random routing remain outstanding.

R prediction-function generation is outside the supported feature scope. Independent R comparisons validate the numerical fitting and pruning routines.

## Node fitting

- Squared error: weighted means or weighted QR least squares. QR is column-pivoted and reorthogonalized; rank-deficient columns get zero coefficients. Numerical columns are centered/scaled. Node-mean imputation and missing indicators are saved. Multiple-linear SSE categorical fitting uses a global sorted level list, including excluded rows and missingness sorted as `NA`. The first global level is the reference when locally present; otherwise the last local level is the reference. Missing indicators represent nonreference missing levels. Other model families retain their local sorted baseline. See [categorical validation](categorical-linear-validation.md).
- Polynomial: search individual numerical fitting variables and degrees 1 through the configured maximum (maximum 6); minimize training loss. This is not yet GUIDE's full model-selection testing procedure.
- Stepwise (experimental, opt-in; further native parity work deferred by user decision): grouped forward F-tests with Bonferroni-adjusted entry alpha and optional backward elimination at alpha. A feature's dummy columns and missing indicator enter/leave together. Tests use QR effective rank and residual degrees of freedom and compare log F tails to avoid ordinary-probability underflow; only exactly zero residual loss receives the perfect-fit shortcut, preserving response-unit invariance. `max_variables=0` removes the user-imposed group limit. Only squared-error models are supported. Fifteen root-only native cases per version validate scoped coefficients/predictions and preserve two unresolved stepwise selection/fallback differences; the original numeric multiple-linear fallback is resolved; see [linear validation](linear-validation.md). All-subsets search and exact GUIDE 46.3 testing/fallback conventions remain outstanding.
- Constant quantile: weighted empirical inverse CDF (smallest value reaching the requested cumulative weight). Sample quantiles used for binning are interpolated type 7.
- Linear/polynomial quantile: minimize weighted pinball loss with a pure Rust primal-dual predictor-corrector optimizer. The linear program is `min sum(w*(tau*u+(1-tau)*v))`, subject to `X*beta+u-v=y`, `u,v>=0`; its dual has `X'*a=0`, `-(1-tau)*w<=a<=tau*w`. Column-pivoted QR computes Newton directions. When the design contains a nonzero constant column, responses are centered at the first active response and that shift is restored in the intercept; models without an intercept are not centered. Inputs are scaled by maximum absolute column/centered-response values and maximum weight, including scales smaller than one. The iteration limit is 100; convergence requires primal feasibility, dual stationarity, nonnegative slacks, complementarity and an objective-gap check with base tolerance 1e-9 in scaled units. `stats::quantile_regression` exposes coefficients, dual variables, objective, gap and convergence status. Tree node status and fit-report warnings expose nonconvergence; numerical initialization failure retains a constant prediction with failed convergence status. Tied optima may have different coefficient vectors from simplex methods. [R's quantile regression documentation](https://search.r-project.org/CRAN/refmans/quantreg/html/rq.html) describes the independent Barrodale–Roberts solver used in tests; [its interior-point documentation](https://search.r-project.org/CRAN/refmans/quantreg/html/rq.fit.fnb.html) discusses nonunique optima. This optimizer is independently implemented, not a translation of R or GUIDE code.
- Dual quantiles: constant lower/upper estimates minimize summed pinball losses and use below/between/above response groups for association. Ensembles average corresponding quantiles, preserving their order. These intervals are conditional quantile estimates, not calibrated confidence intervals. Nonconstant simultaneous quantiles remain unsupported.
- Poisson: constant exposure-adjusted rate or log-link IRLS. Exposure sums are scaled before averaging to avoid overflow. Linear means are evaluated as `exp(eta + log(exposure))` in fitting and prediction, preserving cancellation between log-rate and log-exposure. Deviance uses a series near the fitted mean to avoid subtractive cancellation; nonfinite means cannot appear to have zero deviance.
- Logistic: binary 0/1 observations, constant proportion or logit-link IRLS. GLM fitting uses step-halving and up to 100 iterations; convergence requires a maximum coefficient update below 1e-7. Small objective improvement alone no longer declares convergence. All-zero Poisson responses and all-zero/all-one Bernoulli responses retain exact constant models. A tested completely separated logistic fit reports nonconvergence; this is not a general separation diagnostic.

Numeric/categorical multiple-linear squared-error fits use a nominal-column minimum before fitting: `p+7` active rows without numeric global missing flags, or `p+m+3` with `m>0` numeric flags. Here `p` counts declared numeric fitting columns plus each categorical feature's global level count minus one. Categorical missingness is a level; it does not count toward `m`. Constant/collinear columns and excluded input rows affect this global design. QR rank determines estimation after that threshold. Periodic and other model families retain their existing rank-aware fallback.

The `prediction_truncation` option is supported for multiple-linear squared-error models: `none` (Rust default), `node_range`, `node_range_expanded` (10% range padding each side), and `global_range` (native default). Bounds exclude zero-weight/missing-response rows and are stored in each linear node. Global bounds stay fixed from full active training data across CV; node bounds are fold-local. Fitting, variable-selection residuals and weakest-link training risks use unbounded least squares; prediction and held-out loss apply the bounds. Older models without the optional fields remain unbounded and are not refitted. A documented nine-row/four-predictor native fit violates a missing-indicator normal equation; Rust keeps the independent QR optimum (SSE 2.70 versus native 3.25). See [linear validation](linear-validation.md).

Fitting linear models with more terms than observations falls back to a constant. Term scaling, imputations, coefficient vectors and links are serialized. Nonfinite fitted models/predictions are rejected; iterative solver failures can instead retain a finite fallback as described above. More detailed failure diagnostics and periodic/other-family native fallback rules remain outstanding. Native multiple-linear acceptance covers seventeen numerical-tree cases per version through depth three, including weighted fits, missing regressors/split values, fixed-size paths and LOOCV. Independent evidence preserves correct CV where native selects a different tree size; broader model-based growth/pruning remains open (see [linear validation](linear-validation.md)). Forty-one further categorical-linear cases per version cover fitting, mixed-design guards, limits and LOOCV; the original balanced-residual-sign selection gap is resolved in reference9 (see [categorical validation](categorical-linear-validation.md)). Multiple-linear SSE fitting stops when its sole eligible nonconstant split predictor has exactly zero sign association; positive scores with p-values above 0.99 still reach search. Thirty-six cases per native version verify this narrow rule, weak/strong controls and preserved interaction searches. Importance and other model families retain their existing paths; multi-predictor zero-score fallback remains unverified (see [selection validation](selection-validation.md)). Thirty-nine further cases per native version verify categorical orientations and held-out missing/unseen routes; a separate categorical CV-table difference retains independently verified CV (see [orientation validation](orientation-validation.md)).

## Pruning and ensembles

The cost-complexity path repeatedly removes one weakest link with alpha = (collapsed risk − subtree leaf risk)/(leaf count − 1), using globally normalized training risk. Tied candidates use parent-before-child, left-before-right traversal. Separate stages with equal alphas are retained. Fixed-size pruning chooses the first path tree with at most the requested number of leaves; pruning an entire branch can undershoot the requested size. Cost-complexity pruning applies every stage at or below the requested alpha.

CV rebuilds trees in seeded folds (stratified for classification). Classification folds retain full-training priors, including when priors were estimated; held-out costs are averaged over actual validation cases without prior reweighting. CV evaluates the full fold tree for the initial nontrivial candidate, geometric alpha intervals for intermediate candidates, and fold roots for the final candidate. It selects the smallest eligible tree within the configured SE allowance. Default CV is 10 folds and 0.25 SE; insufficient rows produce a diagnostic, not an implicit change of folds.

The naive SE is the population standard deviation of normalized weighted row losses divided by sqrt(N). Specifically, with u_i = N w_i / sum(w), m = sum(u_i loss_i)/N and SE = sqrt(sum((u_i loss_i − m)^2))/N. Classification uses w_i = 1. Weight/loss scaling prevents numerical underflow and overflow. GUIDE reports weighted losses in sum(w × loss)/N units; native comparisons explicitly convert both means and SEs to Rust's normalized weight units.

Rust deliberately retains correct weakest-link selection where the pinned native CV implementation ignores a cheaper branch because of node-number ordering; see [the counterexamples and evidence](native-cv-difference.md). Native-compatible final predictions in the current cases do not imply identical intermediate CV errors. Mean/bootstrap-SE, median-CV and nontrivial-tree variants outside this implementation remain outstanding. Random multi-fold CV is reproducible within Rust but does not reproduce Fortran's random stream.

Validation data must supply exposures if training used them. Trees are checked for nonfinite statistics before pruning, and nonfinite validation losses return errors.

Bagging samples rows with replacement. Forests additionally sample features at each node, defaulting to floor(sqrt(p)) for classification and floor(p/3) for regression, at least one. Forest configurations require pruning disabled. OOB evaluation uses only trees that did not sample each observation; rows with no such trees are counted and excluded from the OOB loss. Ensemble predictions average probabilities or response predictions.

## Importance

For constant squared-error and classification trees, accumulate sqrt(node size) times the one-degree-of-freedom chi-square equivalent of each variable's test probability at intermediate nodes. Log probabilities feed the inverse directly, avoiding the former 1e-300 floor and score saturation. Use a separate seeded response-permutation loop to estimate null means, then divide observed scores by these means. Defaults are four split levels and 300 permutations.

The Loh–Zhou rank-based approximation counts how many raw scores exceed a quantile of permutation maxima, selects that many highest adjusted scores, and uses the boundary midpoint. At zero/all selected or tied boundaries, a numerical adjusted threshold is unavailable and is returned as null. Normalization uses the 95% midpoint when defined. Features straddling tied 95%/99% boundaries have group `indeterminate`; feature names do not resolve statistical ties. The rank-based `important_count` can therefore differ from the number of resolved group memberships. Positive raw scores with zero estimated null mean also have an indeterminate group and no normalized score; their scalar adjusted score is a zero compatibility placeholder accompanied by a warning. Eight native cases per version compare important sets/rank relations, with independently checked raw scores; exact calibration magnitudes, native fallback normalization, 50% thresholds and specialized responses remain outstanding. See [importance validation](importance-validation.md).
